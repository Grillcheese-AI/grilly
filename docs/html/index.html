Overview

What is Grilly?

Grilly is a Vulkan-first neural network framework that runs on AMD, NVIDIA, and Intel GPUs using compute shaders. It provides a PyTorch-like API (grilly.nn and grilly.functional) while exposing a low-level Vulkan backend for high-performance kernels such as attention, convolution, FAISS-style similarity search, and spiking neural networks.

The HTML docs focus on public APIs and usage. Internal backend modules are documented for contributors and advanced users.

Quick Start

import numpy as np
 import grilly
 
 backend = grilly.Compute()
 
 x = np.random.randn(2, 64).astype(np.float32)
 w = np.random.randn(128, 64).astype(np.float32)
 b = np.zeros(128, dtype=np.float32)
 
 y = backend.fnn.linear(x, w, b)
 y = backend.fnn.activation_gelu(y)
 print(y.shape)

This example uses the low-level Compute backend. For a PyTorch-like API, see grilly.nn and the tutorials.

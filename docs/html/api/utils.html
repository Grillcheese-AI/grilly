Data Utilities

  • Dataset, TensorDataset, ArrayDataset, Subset, ConcatDataset
  • RandomSampler, SequentialSampler, BatchSampler
  • DataLoader, default_collate, random_split
  • Transforms: Compose, ToFloat32, Normalize, Flatten, RandomNoise, RandomFlip, OneHot, Lambda

See Tutorial 09 for end-to-end data loading.

Device Management

  • get_device, set_device, device_count
  • DeviceManager, get_device_manager
  • get_vulkan_backend, get_cuda_backend, get_torch
from grilly.utils import get_device_manager
 
 dm = get_device_manager()
 array = dm.to_vulkan([1, 2, 3])

Tensor Conversion

  • to_vulkan, to_vulkan_batch
  • to_vulkan_gpu
  • from_vulkan
  • ensure_vulkan_compatible
  • VulkanTensor
import torch
 from grilly.utils import to_vulkan, from_vulkan
 
 t = torch.randn(4, 16)
 v = to_vulkan(t)
 
 # Run a Vulkan op (via grilly.nn or compute backend)...
 
 t2 = from_vulkan(v, device="cpu")

HuggingFace Bridge

  • HuggingFaceBridge
  • get_huggingface_bridge

Enables loading weights from HuggingFace models without a PyTorch runtime on GPU.

Vulkan Sentence Transformer

  • VulkanSentenceTransformer
from grilly.utils import VulkanSentenceTransformer
 
 model = VulkanSentenceTransformer("all-MiniLM-L6-v2")
 embeddings = model.encode(["hello", "world"])

PyTorch Compatibility

  • Tensor, tensor, zeros, ones, randn, arange, cat, stack
  • from_numpy, to_numpy
  • pytorch_ops: add, matmul, relu, gelu, softmax, layer_norm, conv2d, max_pool2d

These helpers provide a PyTorch-like API surface for quick migrations.

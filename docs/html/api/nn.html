grilly.nn

PyTorch-like neural network modules and autograd utilities.

Home Installation API Reference Tutorials

Overview

The grilly.nn package mirrors the structure of torch.nn, with modules backed by Vulkan compute shaders where available. Inputs are typically numpy arrays (float32) or VulkanTensor objects, and some modules integrate with Grilly autograd.

Base Classes

  • Module - Base class for all layers.
  • Parameter - Trainable parameter wrapper.

Core Layers

Layer Notes
LinearDense projection, Vulkan-accelerated.
LayerNormLayer normalization.
DropoutDropout regularization.

SequentialChain layers in sequence.
ResidualResidual wrapper for skip connections.
MultiheadAttentionStandard attention module.

Autograd

Autograd utilities live under grilly.nn.autograd and provide a PyTorch-like operator overloading system.

  • Variable, Function, FunctionCtx, GradFn
  • Tensor factory functions: tensor, zeros, ones, randn, rand, linspace, arange, eye, full
  • Operators: add, sub, mul, div, matmul, pow, exp, log, sqrt, relu, gelu, silu, softmax
  • Reductions: sum, mean, max, min, var, std, norm
  • Context: enable_grad, no_grad, is_grad_enabled
  • Loss ops: cross_entropy, mse_loss, bce_loss, nll_loss, kl_div_loss

See Tutorials 07 and 08 for detailed autograd usage and custom Function examples.

Example

import numpy as np
 import grilly.nn as nn
 
 model = nn.Sequential(
     nn.Linear(128, 64),
     nn.GELU(),
     nn.Linear(64, 10)
 )
 
 x = np.random.randn(32, 128).astype(np.float32)
 y = model(x)
 print(y.shape)

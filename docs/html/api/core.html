VulkanCompute

The central backend. It composes all Vulkan-accelerated modules and exposes them under namespaces like compute.fnn, compute.attention, compute.memory, and compute.faiss.

Constructor

compute = grilly.Compute(shader_dir=None)

If shader_dir is provided, it overrides the default shader lookup path.

Core Attributes

  • compute.core - VulkanCore instance (device, queues, memory).
  • compute.pipelines - Pipeline registry and descriptor cache.
  • compute.shaders - Loaded shader registry.

Operation Modules

  • compute.fnn - Feedforward ops (linear, activations, layernorm).
  • compute.attention - Attention kernels and Flash Attention 2.
  • compute.memory - Memory read/write and context ops.
  • compute.faiss - Vector similarity search (distance, topk).
  • compute.snn - Spiking neural network kernels.
  • compute.learning - EWC, NLMS, natural gradient, whitening.
  • compute.fft - FFT kernels and spectral ops.
  • compute.conv - Convolution kernels.
  • compute.pooling - Pooling kernels.
  • compute.normalization - Norm kernels beyond layernorm.
  • compute.lora - LoRA-related kernels.
  • compute.affect - Affective processing ops.
  • compute.cells - Place and time cells.

Architecture Selection

compute.set_architecture("bert")

Selecting an architecture enables architecture-specific shader variants (BERT, GPT, T5, DistilBERT, etc). It also exposes convenience wrappers on the compute instance such as compute.flash_attention2.

Resource Management

compute.cleanup()

Call this when you are done to release Vulkan resources and buffer pools.

Example

import numpy as np
 import grilly
 
 compute = grilly.Compute()
 compute.set_architecture("bert")
 
 x = np.random.randn(2, 64).astype(np.float32)
 w = np.random.randn(128, 64).astype(np.float32)
 b = np.zeros(128, dtype=np.float32)
 
 y = compute.fnn.linear(x, w, b)
 y = compute.fnn.activation_gelu(y)
 print(y.shape)
 
 compute.cleanup()

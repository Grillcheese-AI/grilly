Usage

Functional APIs accept numpy arrays (float32) or VulkanTensor objects. They mirror torch.nn.functional patterns and map to Vulkan kernels via the compute backend. 

import numpy as np
 from grilly import functional as F
 
 x = np.random.randn(4, 128).astype(np.float32)
 w = np.random.randn(256, 128).astype(np.float32)
 b = np.zeros(256, dtype=np.float32)
 
 y = F.linear(x, w, b)
 y = F.gelu(y)
 y = F.dropout(y, p=0.1)

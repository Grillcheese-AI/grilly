Example

import numpy as np
 import grilly.nn as nn
 from grilly.optim import Adam
 
 model = nn.Sequential(
     nn.Linear(128, 64),
     nn.GELU(),
     nn.Linear(64, 10)
 )
 
 # Collect parameters
 params = model.parameters()
 optimizer = Adam(params, lr=1e-3)
 
 # Dummy training step
 x = np.random.randn(16, 128).astype(np.float32)
 y = model(x)
 loss = (y ** 2).mean()
 
 optimizer.zero_grad()
 loss.backward()
 optimizer.step()

The example assumes the model outputs autograd Variables. For pure numpy workflows, use manual gradient updates or the VulkanCompute backend's learning kernels.

Overview

The backend package implements Vulkan compute execution. Most users should interact with grilly.Compute and the public APIs. The modules below are intended for contributors and advanced integrations.

Core Infrastructure

  • base.py - Vulkan availability and constants.
  • core.py - Vulkan device, queue, memory, and buffer management.
  • pipelines.py - Pipeline creation, caching, descriptor sets.
  • shader_registry.py - Shader loading and metadata.
  • buffer_pool.py - GPU buffer pooling for reuse.
  • vma_wrapper.py - PyVMA integration for memory allocation.

Main Entry Points

  • compute.py - VulkanCompute class (composition of modules).
  • snn_compute.py - High-level spiking neural network interface.
  • autograd_core.py - Backend autograd and tracing utilities.

Operation Modules

Neural Ops

  • fnn.py - Feedforward ops (linear, activations, layernorm)
  • conv.py - Convolution kernels
  • pooling.py - Pooling kernels
  • normalization.py - Batch and layer normalization ops
  • attention.py - Attention kernels, Flash Attention 2
  • lora.py - LoRA helpers and kernels

Specialized Ops

  • snn.py - Spiking neural network kernels
  • memory.py - Memory read/write and context ops
  • faiss.py - Distance, topk, IVF filters
  • learning.py - EWC, NLMS, natural gradient, whitening
  • fft.py - FFT and spectral ops
  • contrastive.py - Contrastive loss and gradients

Domain-Specific

  • capsule_transformer.py - Capsule memory and transformer blocks
  • cells.py - Place cells and time cells
  • affect.py - Affective processing ops
  • hilbert.py - Hilbert curve utilities
  • snn_visualizer.py - Optional SNN visualization helpers

GLU Helpers

  • _glu_append.py - Fused GLU variants (SwiGLU, ReGLU, GeGLU)

Usage Guidance

Use backend modules if you need custom Vulkan workflows or want to extend kernel coverage. For normal usage, prefer the high-level APIs in grilly and grilly.nn.

Requirements

  • Python 3.10+
  • Vulkan-capable GPU (AMD, NVIDIA, Intel)
  • Up-to-date GPU drivers
  • Vulkan SDK or runtime tools for your OS

Grilly uses Vulkan compute shaders. If Vulkan is not available, some operations may fall back to CPU. Always verify Vulkan is working before running GPU workloads.

Install Grilly

pip install grilly

For editable installs from source, run pip install -e . inside the repo.

Vulkan Installation

Linux (Ubuntu/Debian)

sudo apt-get update
 sudo apt-get install -y \
   vulkan-tools vulkan-validationlayers \
   mesa-vulkan-drivers libvulkan1

For NVIDIA, install the latest recommended NVIDIA driver. For AMD/Intel, Mesa packages provide Vulkan drivers on most distros.

Linux (Fedora)

sudo dnf install -y \
   vulkan-tools vulkan-validation-layers \
   mesa-vulkan-drivers vulkan-loader

On Arch, install vulkan-tools and the appropriate driver package (nvidia, amdvlk, or vulkan-intel).

Windows

  1. Install the latest GPU driver from AMD, NVIDIA, or Intel.
  2. Install the Vulkan SDK from LunarG (includes vulkaninfo and validation layers).
https://vulkan.lunarg.com/sdk/home

macOS

  1. Install the Vulkan SDK from LunarG (includes MoltenVK).
  2. Ensure the SDK environment variables are set in your shell.
https://vulkan.lunarg.com/sdk/home

macOS uses Metal through MoltenVK. Some Vulkan features may not be available; run the Grilly test suite to confirm shader compatibility.

Verify Vulkan

vulkaninfo

On Windows, launch a "Developer Command Prompt" if the tool is not on PATH. On macOS, use the SDK-provided vulkaninfo binary if the system one is not available.

Install PyVMA (Recommended)

PyVMA is a Python binding for Vulkan Memory Allocator (VMA). It improves buffer reuse, reduces fragmentation, and prevents memory access issues on some AMD systems.

Automatic Installer (All OS)

python -m grilly.scripts.install_pyvma

The installer checks for a compiler, builds the VMA library, installs PyVMA, and validates that the bindings are available.

Manual Build - Windows

  1. Install "Visual Studio Build Tools" with C++ workload.
  2. Open "Developer Command Prompt for VS".
cd grilly
 git clone https://github.com/realitix/pyvma.git
 cd pyvma\pyvma\pyvma_build
 
 cl.exe /c /I"include" /DVMA_IMPLEMENTATION /DVMA_STATIC_VULKAN_FUNCTIONS=0 ^
   /nologo /W3 /Ox /Oi /GF /EHsc /MD /GS /Gy /Zc:inline /Zc:wchar_t /Gd /TP ^
   /Fo"vk_mem_alloc.obj" "vk_mem_alloc.h"
 
 lib.exe /OUT:"vk_mem_alloc.lib" "vk_mem_alloc.obj"
 
 cd ..\..
 pip install .

Manual Build - Linux

sudo apt-get install -y build-essential
 cd grilly
 git clone https://github.com/realitix/pyvma.git
 cd pyvma/pyvma/pyvma_build
 
 g++ -std=c++11 -fPIC -x c++ -I"include" \
   -DVMA_IMPLEMENTATION -DVMA_STATIC_VULKAN_FUNCTIONS=0 \
   -c vk_mem_alloc.h -o vk_mem_alloc.o
 
 ar rvs libvk_mem_alloc.a vk_mem_alloc.o
 
 cd ../..
 pip install .

Manual Build - macOS

xcode-select --install
 cd grilly
 git clone https://github.com/realitix/pyvma.git
 cd pyvma/pyvma/pyvma_build
 
 clang++ -std=c++11 -fPIC -x c++ -I"include" \
   -DVMA_IMPLEMENTATION -DVMA_STATIC_VULKAN_FUNCTIONS=0 \
   -c vk_mem_alloc.h -o vk_mem_alloc.o
 
 libtool -static -o libvk_mem_alloc.a vk_mem_alloc.o
 
 cd ../..
 pip install .

Verify PyVMA

python - <<'PY'
 import pyvma
 print("PyVMA:", pyvma.__version__)
 print("vmaCreateAllocator:", pyvma.vmaCreateAllocator)
 PY

Environment Variables

Variable Purpose
VK_GPU_INDEX Select GPU index when multiple GPUs are present.
GRILLY_DEBUG Enable debug logging.
ALLOW_CPU_VULKAN Allow CPU fallback when GPU is not available.

Troubleshooting

  • vulkaninfo not found: install Vulkan SDK or vulkan-tools.
  • Vulkan init fails: update GPU drivers and verify Vulkan works.
  • PyVMA build errors: ensure a C++ compiler is installed and on PATH.
  • macOS limitations: MoltenVK does not expose all Vulkan features.

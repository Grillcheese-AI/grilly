01 - Quick Start

Basic GPU-accelerated operations using VulkanCompute.

Home Installation API Reference Tutorials

Goal

Initialize the Vulkan backend, run a few core operations (activations, linear, layernorm), and validate outputs. This mirrors tutorials/01_quickstart.py.

Step 1 - Initialize the Backend

import numpy as np
 from grilly import Compute
 
 compute = Compute()
 print(f"GPU: {compute.core.device_properties.deviceName}")

Step 2 - Activations

x = np.random.randn(4, 8).astype(np.float32)
 
 relu_out = compute.fnn.activation_relu(x)
 gelu_out = compute.fnn.activation_gelu(x)
 softmax_out = compute.fnn.activation_softmax(x)
 
 print(relu_out.shape)
 print(gelu_out.shape)
 print(softmax_out.sum(axis=-1))

The softmax rows should sum to roughly 1.0.

Step 3 - Linear Layer

x = np.random.randn(2, 64).astype(np.float32)
 weights = np.random.randn(128, 64).astype(np.float32)
 bias = np.random.randn(128).astype(np.float32)
 
 y = compute.fnn.linear(x, weights, bias)
 print(y.shape)  # (2, 128)

Step 4 - Layer Normalization

x = np.random.randn(2, 64).astype(np.float32)
 gamma = np.ones(64, dtype=np.float32)
 beta = np.zeros(64, dtype=np.float32)
 
 y = compute.fnn.layernorm(x, gamma, beta)
 print(y.mean(), y.std())

LayerNorm outputs should have mean near 0 and std near 1 (per row).

Cleanup

compute.cleanup()

Release Vulkan resources when done.

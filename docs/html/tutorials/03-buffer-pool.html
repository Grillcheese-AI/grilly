03 - Buffer Pool

GPU buffer pooling to reduce allocation overhead.

Home Installation API Reference Tutorials

Overview

Grilly uses a per-module buffer pool to reuse GPU buffers across operations. This improves performance by avoiding repeated allocations and frees, especially in tight training loops.

Check VMA Availability

from grilly import Compute
 from grilly.backend.buffer_pool import is_vma_available
 
 compute = Compute()
 print("VMA available:", is_vma_available())

VMA integration improves buffer reuse and stability. Install PyVMA for best results.

Inspect Pool Statistics

import numpy as np
 
 x = np.random.randn(64, 256).astype(np.float32)
 compute.fnn.activation_relu(x)
 
 pool = compute.fnn.buffer_pool
 print("Pool:", pool)
 
 for _ in range(20):
     compute.fnn.activation_relu(x)
     compute.fnn.activation_gelu(x)
 
 stats = pool.get_stats()
 print("Hit rate:", stats["hit_rate"])
 print("Allocations:", stats["allocations"])

How It Works

  • Buffers are bucketed by size.
  • Requests reuse existing buffers when possible.
  • Hit rate improves after warmup.

Each compute instance owns its own pool to avoid cross-session issues.

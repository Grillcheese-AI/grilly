04 - Polynomial Regression

Manual gradients with numpy, plus GPU-accelerated activations.

Home Installation API Reference Tutorials

Objective

Fit a polynomial to sin(x) using manual gradients. This tutorial shows how Grilly can be mixed with numpy in a classical training loop.

Training Loop (Manual Gradients)

import numpy as np
 import math
 from grilly import Compute
 
 compute = Compute()
 
 x = np.linspace(-math.pi, math.pi, 2000).astype(np.float32)
 y = np.sin(x).astype(np.float32)
 
 a = np.float32(np.random.randn())
 b = np.float32(np.random.randn())
 c = np.float32(np.random.randn())
 d = np.float32(np.random.randn())
 
 learning_rate = 1e-6
 
 for t in range(2000):
     y_pred = a + b * x + c * x ** 2 + d * x ** 3
     loss = np.sum((y_pred - y) ** 2)
 
     grad_y_pred = 2.0 * (y_pred - y)
     grad_a = grad_y_pred.sum()
     grad_b = (grad_y_pred * x).sum()
     grad_c = (grad_y_pred * x ** 2).sum()
     grad_d = (grad_y_pred * x ** 3).sum()
 
     a -= learning_rate * grad_a
     b -= learning_rate * grad_b
     c -= learning_rate * grad_c
     d -= learning_rate * grad_d

GPU-Accelerated Activations

After training, run activations on GPU for analysis or post-processing.

y_final = a + b * x + c * x ** 2 + d * x ** 3
 y_final_2d = y_final.reshape(1, -1)
 
 relu_out = compute.fnn.activation_relu(y_final_2d)
 gelu_out = compute.fnn.activation_gelu(y_final_2d)

Key Takeaways

  • Manual gradients are useful for debugging and teaching.
  • GPU ops can be used for expensive transforms.
  • Buffer pooling improves repeated activation performance.

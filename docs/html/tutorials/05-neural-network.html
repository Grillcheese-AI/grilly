05 - Neural Network Training

Train a small network with Vulkan-accelerated forward passes.

Home Installation API Reference Tutorials

Objective

Fit sin(x) using a two-layer network. Forward passes use GPU kernels while gradients are computed manually with numpy.

Model Setup

import numpy as np
 import math
 from grilly import Compute
 
 compute = Compute()
 
 N = 64
 D_in = 1
 H = 32
 D_out = 1
 
 x = np.linspace(-math.pi, math.pi, N).reshape(N, D_in).astype(np.float32)
 y = np.sin(x).astype(np.float32)
 
 def xavier_init(in_dim, out_dim):
     scale = np.sqrt(2.0 / (in_dim + out_dim))
     return (np.random.randn(out_dim, in_dim) * scale).astype(np.float32)
 
 w1 = xavier_init(D_in, H)
 b1 = np.zeros(H, dtype=np.float32)
 w2 = xavier_init(H, D_out)
 b2 = np.zeros(D_out, dtype=np.float32)

Forward and Backward

learning_rate = 1e-3
 epochs = 500
 
 for epoch in range(epochs):
     # Forward (GPU)
     h = compute.fnn.linear(x, w1, b1)
     h_relu = compute.fnn.activation_relu(h)
     y_pred = compute.fnn.linear(h_relu, w2, b2)
 
     # Loss
     diff = y_pred - y
     loss = np.mean(diff ** 2)
 
     # Gradients (manual)
     grad_y_pred = (2.0 / N) * diff
     grad_h_relu = grad_y_pred @ w2
     grad_w2 = grad_y_pred.T @ h_relu
     grad_b2 = np.sum(grad_y_pred, axis=0)
 
     grad_h = grad_h_relu * (h > 0).astype(np.float32)
     grad_w1 = grad_h.T @ x
     grad_b1 = np.sum(grad_h, axis=0)
 
     # Update
     w1 -= learning_rate * grad_w1
     b1 -= learning_rate * grad_b1
     w2 -= learning_rate * grad_w2
     b2 -= learning_rate * grad_b2

Takeaways

  • GPU kernels can be used for forward passes with numpy gradients.
  • Manual gradients are useful for understanding backprop.
  • For full GPU training, see Tutorial 10.

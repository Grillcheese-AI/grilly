08 - Advanced Activations

GCU, RoSwish, SwiGLU, and fused activation benchmarks.

Home Installation API Reference Tutorials

Activation Overview

  • GCU - Growing Cosine Unit: f(x) = x * cos(x)
  • RoSwish - Learnable gated activation with alpha and beta.
  • SwiGLU - Gated activation for transformer FFN blocks.

Basic Usage

import numpy as np
 import grilly
 
 compute = grilly.Compute()
 x = np.array([-2, -1, 0, 1, 2], dtype=np.float32)
 
 print(compute.activation_gcu(x))
 print(compute.activation_roswish(x, alpha=1.0, beta=1.0))
 
 x_ffn = np.random.randn(2, 4, 2 * 256).astype(np.float32)
 y = compute.activation_swiglu(x_ffn)

Learnable RoSwish Module

import grilly.nn as nn
 
 roswish = nn.RoSwish(alpha_init=1.0, beta_init=1.0, learnable=True)
 out = roswish(x)

Fused Linear + Activation

x = np.random.randn(32, 256).astype(np.float32)
 w = np.random.randn(512, 256).astype(np.float32)
 b = np.random.randn(512).astype(np.float32)
 
 y = compute.fnn.fused_linear_gcu(x, w, b)
 z = compute.fnn.fused_linear_roswish(x, w, b)

Objective

Fit exp(x) with a polynomial using Grilly's autograd system. This mirrors tutorials/07_autograd.py.

Setup

import numpy as np
 from grilly.nn.autograd import linspace, randn, no_grad
 
 # x in [-1, 1], y = exp(x)
 x = linspace(-1, 1, 2000)
 y = x.exp()
 
 a = randn(requires_grad=True)
 b = randn(requires_grad=True)
 c = randn(requires_grad=True)
 d = randn(requires_grad=True)

Training Loop

learning_rate = 1e-5
 
 for t in range(5000):
     y_pred = a + b * x + c * x ** 2 + d * x ** 3
     loss = ((y_pred - y) ** 2).sum()
 
     a.zero_grad()
     b.zero_grad()
     c.zero_grad()
     d.zero_grad()
     loss.backward()
 
     with no_grad():
         a.data -= learning_rate * a.grad
         b.data -= learning_rate * b.grad
         c.data -= learning_rate * c.grad
         d.data -= learning_rate * d.grad

Notes

  • Variables track gradients automatically through operator overloading.
  • Use no_grad() for parameter updates to avoid tracking.
  • Use zero_grad() before each backward pass.

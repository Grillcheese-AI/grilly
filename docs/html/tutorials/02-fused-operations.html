02 - Fused Operations

Combine multiple kernels into a single GPU dispatch for higher throughput.

Home Installation API Reference Tutorials

Why Fused Ops?

Fused shaders reduce intermediate memory writes. For example, a linear projection followed by GELU can be executed as a single kernel. This improves latency and throughput for transformer workloads.

Benchmark: Linear + GELU

import numpy as np
 import time
 from grilly import Compute
 
 compute = Compute()
 
 x = np.random.randn(32, 256).astype(np.float32)
 w = np.random.randn(512, 256).astype(np.float32)
 b = np.random.randn(512).astype(np.float32)
 
 # Warmup
 for _ in range(5):
     compute.fnn.linear(x, w, b)
 
 iterations = 100
 
 # Separate ops
 start = time.perf_counter()
 for _ in range(iterations):
     out = compute.fnn.linear(x, w, b)
     out = compute.fnn.activation_gelu(out)
 separate_ms = (time.perf_counter() - start) / iterations * 1000
 
 # Fused op
 start = time.perf_counter()
 for _ in range(iterations):
     out = compute.fnn.fused_linear_gelu(x, w, b)
 fused_ms = (time.perf_counter() - start) / iterations * 1000
 
 print("Separate:", separate_ms, "ms")
 print("Fused:", fused_ms, "ms")

Available Fused Ops

  • fused_linear_gelu
  • fused_linear_relu
  • fused_linear_silu
  • fused_linear_gcu
  • fused_linear_roswish

Fused GLU variants (SwiGLU, ReGLU, GeGLU) are implemented in the backend for transformer FFN layers. Use them where appropriate for LLM-style architectures.

Performance Tips

  • Use fused ops inside transformer blocks (QKV and FFN).
  • Warm up kernels before benchmarking.
  • Keep batch sizes consistent for stable timings.

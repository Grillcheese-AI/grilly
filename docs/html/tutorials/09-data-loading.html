Dataset and DataLoader

Grilly provides dataset abstractions and DataLoader utilities in grilly.utils.data. 

import numpy as np
 from grilly.utils.data import TensorDataset, DataLoader
 
 X = np.random.randn(1000, 784).astype(np.float32)
 y = np.random.randint(0, 10, 1000)
 
 dataset = TensorDataset(X, y)
 loader = DataLoader(dataset, batch_size=64, shuffle=True)
 
 for X_batch, y_batch in loader:
     print(X_batch.shape, y_batch.shape)
     break

Transforms

from grilly.utils.data import Compose, Normalize, Flatten, OneHot
 
 transform = Compose([
     Flatten(),

 ])

Notes on Built-in Datasets

Some environments provide dataset helpers (for example MNIST and CIFAR10). If those modules are not present, you can load data manually and wrap it with TensorDataset or ArrayDataset.
